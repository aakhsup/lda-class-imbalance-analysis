# Влияние дисбаланса классов на LDA: анализ датасета Iris

Лабораторная работа по исследованию того, как искусственное создание дисбаланса классов влияет на работу линейного дискриминантного анализа (LDA). На основе сгенерированного датасета последовательно создаются его модификации с повторением объектов одного класса (в 2, 5, 10, 20, 50, 100, 1000 и 10 000 раз) и анализируется смещение решающей границы.

---

## 📖 О проекте

Цель работы — наглядно продемонстрировать, как изменение априорных вероятностей классов (priors) через простое дублирование данных приводит к смещению разделяющей функции LDA. Это важный практический аспект: модели чувствительны к дисбалансу, и простое «размножение» данных одного из классов искажает границы классификации.

### Что реализовано

| № | Задача | Инструменты |
|---|--------|-------------|
| 1 | Генерация сбалансированного синтетического датасета (`df1`) на основе Iris | `make_blobs`, `pandas` |
| 2 | Табличная статистика по исходному и сгенерированному датасетам | `DataFrame.describe`, `value_counts` |
| 3 | Визуализация по всем парам количественных признаков | `matplotlib`, `seaborn` (scatter + hist/KDE) |
| 4 | Корреляционный анализ (Pearson) | `DataFrame.corr` + heatmap |
| 5 | Создание датасетов с дисбалансом (`df2` … `df10000`) | `pandas.concat` |
| 6 | Построение LDA для каждого датасета | `LinearDiscriminantAnalysis` |
| 7 | Визуализация решающей функции, зон и объектов классов | `matplotlib`, `numpy` |

## 📊 О датасете

**Iris** — классический датасет для задач классификации (Фишер, 1936).

- **Объекты:** 150
- **Признаки:** 4 количественных
  - `sepal_length` — длина чашелистика
  - `sepal_width` — ширина чашелистика
  - `petal_length` — длина лепестка
  - `petal_width` — ширина лепестка
- **Классы (по 50 объектов):** `setosa`, `versicolor`, `virginica`

На основе этого датасета сгенерирован сбалансированный синтетический датасет `df1` (3000 объектов, по 1000 на класс, 4 признака) с помощью `make_blobs`. Именно он используется для дальнейшего исследования влияния дисбаланса.

## 🎯 Ключевые результаты

### Корреляция Пирсона (весь датасет `df1`)

В сгенерированном датасете `df1` признаки имеют иную структуру связей по сравнению с исходным Iris — это ожидаемо, так как `make_blobs` создаёт кластеры в изотропном пространстве. Тем не менее, даже на таком «простом» датасете эффект дисбаланса проявляется ярко.

### Влияние дисбаланса на LDA

При увеличении числа повторений класса `'0'`:

- априорная вероятность этого класса растёт;
- решающая граница смещается в сторону остальных классов;
- зона классификации мажоритарного класса неоправданно расширяется.

Это демонстрирует, что при сильном дисбалансе LDA (и другие линейные модели) склонны предсказывать доминирующий класс, даже если объекты других классов лежат «ближе» к своей области. Простое дублирование данных — **не** способ бороться с дисбалансом, а, наоборот, усиливает его эффект.
